# Brachistochrone

Minimum-time slide of a particle under gravity, no friction. Bernoulli
(1696); the first named calculus-of-variations problem, and the
standard free-final-time nonlinear-kinematics example in every
collocation toolbox.

This page is written as example documentation: geometry, optimal-control
statement, cycloid closed form, how the problem is posed in `eco_opt`,
what the tests check. It can be lifted into the package docs with light
editing.

---

## 1. Question

A bead starts at rest at the origin and must reach a lower point
\((x_f, y_f)\) along a wire in a vertical plane. Gravity is the only
force. Which wire shape minimises the travel time?

A straight line is not optimal: a steep start builds speed that pays
for a longer, flatter finish. The minimiser is a **cycloid**.

---

## 2. Optimal-control problem

Take \(y\) positive *downward* so that the classical cycloid formulae
have no minus signs, and scale \(g=1\). The control \(\theta\) is the
heading from the downward vertical (\(\theta=0\) is free fall,
\(\theta=\pi/2\) is horizontal):

\[
\begin{aligned}
\min_{\theta(\cdot),\, t_f}\quad
& t_f \\
\text{s.t.}\quad
& \dot x = v\sin\theta, \qquad
  \dot y = v\cos\theta, \qquad
  \dot v = g\cos\theta, \\
& (x,y,v)(0)=(0,0,0), \qquad
  (x,y)(t_f)=(\pi, 2), \\
& 0\le\theta\le\pi, \qquad t_f\text{ free}.
\end{aligned}
\]

The default endpoint \((\pi,2)\) is a half-cycloid of generating radius
\(a=1\), so the analytic time is exactly \(\pi\). Any other
\((x_f,y_f)\) with \(y_f>0\) is admitted by the helpers; the tests use
the half-cycloid.

Energy on a frictionless wire is independent of shape:
\(v=\sqrt{2gy}\). The OCP is choosing the *direction* of that speed.

`eco_opt` transcription: three states, one control, Mayer objective
`ocp.min(t_f(sys.t))`, free \(t_f\) with a box \(0.1\le t_f\le 20\).

---

## 3. Cycloid

A cycloid generated by a circle of radius \(a\), rolling under the
\(x\)-axis, with roll angle \(\varphi\):

\[
x=a(\varphi-\sin\varphi), \qquad
y=a(1-\cos\varphi), \qquad
v=2\sqrt{ga}\,\lvert\sin(\varphi/2)\rvert.
\]

Arc-length versus energy gives a *constant* \(\mathrm{d}t/\mathrm{d}\varphi=\sqrt{a/g}\), so

\[
t=\varphi\sqrt{a/g}, \qquad t_f=\varphi_f\sqrt{a/g}.
\]

The heading that traces this curve is half the roll angle,

\[
\theta^\star(\varphi)=\varphi/2 \qquad\Rightarrow\qquad
\theta^\star(t)=\frac{t}{2\sqrt{a/g}}.
\]

(From \(\tan\theta=\mathrm{d}x/\mathrm{d}y=(1-\cos\varphi)/\sin\varphi=\tan(\varphi/2)\).)

For the default endpoint, \(a=1\), \(\varphi_f=\pi\), \(g=1\):

\[
t_f^\star=\pi, \qquad \theta^\star(t)=t/2, \qquad v(t_f)=2.
\]

A general endpoint is reduced to this by solving
\(x_f/y_f=(\varphi_f-\sin\varphi_f)/(1-\cos\varphi_f)\) for \(\varphi_f\)
and setting \(a=y_f/(1-\cos\varphi_f)\).

---

## 4. Pontryagin sketch

Hamiltonian (minimisation form, \(g=1\)):

\[
H = 1 + \lambda_x v\sin\theta + \lambda_y v\cos\theta + \lambda_v \cos\theta.
\]

Stationarity in \(\theta\) (unconstrained interior) gives

\[
\tan\theta^\star = \frac{\lambda_x v}{\lambda_y v+\lambda_v}.
\]

Free \(t_f\) and free \(v(t_f)\) give \(H(t_f)=0\) and \(\lambda_v(t_f)=0\).
The cycloid \(\theta=\varphi/2\) satisfies these conditions; this
example treats that as the independent analytic gate rather than
integrating the costates numerically.

At \(t=0\), \(v=0\), so \(\dot x=\dot y=0\) regardless of \(\theta\):
the initial heading is a single-instant degeneracy. Collocation still
recovers \(\theta\approx 0\) after the first interval. Tests therefore
compare \(\theta(t)\) to \(\varphi/2\) on \(t>0.2\), not at \(t=0\).

## 5. `eco_opt` transcription

```python
sys = eco_opt.System(states=3, controls=1, model=brachistochrone_model)
ocp = eco_opt.Ocp()
ocp.min(eco_opt.t_f(sys.t))
ocp.st(
    system=sys,
    constraints=[
        (0.0, "<=", sys.u[0], "<=", math.pi),
        (0.0, "==", eco_opt.t_0(sys.t)),
        (0.1, "<=", eco_opt.t_f(sys.t), "<=", 20.0),
        (0.0, "==", eco_opt.t_0(sys.y.x)),
        (0.0, "==", eco_opt.t_0(sys.y.y)),
        (0.0, "==", eco_opt.t_0(sys.y.v)),
        (math.pi, "==", eco_opt.t_f(sys.y.x)),
        (2.0, "==", eco_opt.t_f(sys.y.y)),
        ...
    ],
)
```

Collocation: 40 Legendre intervals, degree 4. Constant initial guess
(not the cycloid). `tf_guess` defaults to the analytic \(\pi\).

This is the package’s free-final-time *nonlinear kinematics* gate.
Lenhart 20.4 / `examples/bang_free_tf/` already cover free \(t_f\) on a double
integrator; they do not exercise \(\sin/\cos\) heading dynamics.

## 6. What the test checks

`tests/test_brachistochrone.py`

1. Cycloid helpers recover \(a=1\), \(\varphi_f=\pi\), \(t_f=\pi\).
2. Solver success, \(t_f\) within \(2\times 10^{-3}\) of \(\pi\).
3. Endpoints \((0,0,0)\to(\pi,2)\).
4. States within \(5\times 10^{-3}\) of the cycloid (speed
   \(2\times 10^{-2}\)).
5. Energy \(v^2=2gy\) along the trajectory.
6. Heading tracks \(\varphi/2\) after \(t=0.2\); \(\theta(t_f)\approx\pi/2\).

A solver reporting success is not enough; the wire has to be a cycloid.

## 8. Parameters

| symbol | default | meaning |
|---|---|---|
| \(g\) | 1 | gravity (y downward) |
| \((x_f,y_f)\) | \((\pi, 2)\) | terminal point |
| \(\theta\) | \([0,\pi]\) | heading from downward vertical |

Derived: \(a=1\), \(\varphi_f=\pi\), \(t_f^\star=\pi\), \(v(t_f)=2\).

## 10. Mapping onto the `eco_opt` API (for later docs)

| Concept | Where it appears |
|---|---|
| free final time | `0.1 <= t_f(sys.t) <= 20`, `ocp.min(t_f(sys.t))` |
| nonlinear kinematics | \(\sin\theta,\cos\theta\) in \(\dot x,\dot y,\dot v\) |
| named signals | `sys.y.x`, `.y`, `.v`, `.theta` |
| box on control | `0 <= sys.u[0] <= π` |
| fixed ICs, mixed terminals | \(v(t_f)\) free, \((x,y)(t_f)\) fixed |
| collocation | Legendre, degree 4, 40 intervals |

## 11. Suggested extensions (not implemented)

- DAE / minimum-time *in arc-length* form (PROPT’s DAE brachistochrone).
  Needs algebraic states, which the transcription does not have yet.
- Friction, or a path obstacle.
- General \((x_f,y_f)\); the helpers already support it, only the
  default demo and the test use the half-cycloid.

## 12. References

- Bernoulli, J. (1696). Problema novum ad cujus solutionem mathematici
  invitantur. *Acta Eruditorum*.
- Bryson, A. E. & Ho, Y.-C. (1975). *Applied Optimal Control*, ch. 2.
- Betts, J. T. *Practical Methods for Optimal Control Using Nonlinear
  Programming*. Brachistochrone is the standard free-time demo.
- Dymos / GPOPS-II / PROPT each ship a brachistochrone; the instance

  exactly, rather than a SI-unit endpoint whose time is a fitted float.
