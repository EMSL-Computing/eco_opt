Inventor: Arjun Chakrawal, Environmental Molecular Sciences

Cite this software by name, version and Zenodo DOI. Every release is
archived on Zenodo under
[10.5281/zenodo.24239944](https://doi.org/10.5281/zenodo.24239944), which
covers all versions and resolves to the latest. The Zenodo record lists the
DOI of each version; version 0.1 is
[10.5281/zenodo.24239945](https://doi.org/10.5281/zenodo.24239945).

Also cite:

- **Yop** for the modeling workflow
  ([yoptimization.com](https://www.yoptimization.com); Leek, 2016)
- **CasADi** (Andersson et al., 2019)
- **IPOPT** (Wächter and Biegler, 2006)

Example pages cite the scientific source of each problem (paper or
textbook). Pages that transcribe a Yop-shipped example also link that
Yop page.
